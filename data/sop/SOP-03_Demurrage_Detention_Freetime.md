# Demurrage and Detention Avoidance and Free-time Policy

**Document:** SOP-03  
**Version:** v4.1  
**Effective date:** 2025-11-01  
**Owner:** Import Operations, Meridian Freight Co.

## 1 Definitions

### 1.1 Free time

Free time means the number of calendar days, counted from the date of container discharge, during which no demurrage is charged by the carrier. The Import Operator shall apply this definition when calculating and recording free-time expiry for every import container.

### 1.2 Demurrage vs Detention

Demurrage accrues while the container remains inside the terminal. Detention accrues from gate-out of the container until the empty container is returned. The Import Operator must distinguish between these two charges when monitoring exposure and reviewing carrier invoices.

## 2 Standard Free Time

### 2.1 Contract free time table

The Import Operator shall apply the contract free time set out in the following table; where the Blue Harbor Foods contract applies, its flat free time replaces the carrier figures.

| Carrier / Contract | Dry free time | Reefer free time |
|---|---|---|
| Hanseatic Marine Lines | 7 days | 5 days |
| Orient Container Line | 7 days | 5 days |
| Pacific Star Shipping | 7 days | 4 days |
| Blue Harbor Foods contract (all carriers; replaces the carrier figures) | 10 days | 10 days |

### 2.2 Recording

The Import Operator must record the free-time expiry date in the shipment file on the day the Arrival Notice is issued. No Arrival Notice shall be considered complete until the free-time expiry date has been recorded.

## 3 Monitoring

### 3.1 Daily watch list

Every morning, the Import Operator shall review all containers whose free time expires within 3 days. This daily watch list must be used to identify containers at risk of incurring demurrage or detention so that timely action can be taken.

### 3.2 Consignee reminder

Where customs release or pick-up has not yet been confirmed, the Import Operator must remind the consignee in writing 3 working days before free-time expiry. The written reminder shall be retained in the shipment file.

## 4 Extension and Charges

### 4.1 Extension request

When a delay is foreseeable, the Import Operator shall request a free-time extension in writing from the carrier's D&D desk. The written request and the carrier's response must be kept in the shipment file.

### 4.2 Extension timing

The Import Operator must send the extension request no later than 2 working days before free time expires. Requests submitted after expiry are generally refused by carriers, and the Import Operator shall therefore not defer the request until free time has lapsed.

### 4.3 Charge allocation

Demurrage caused by consignee document delay shall be billed to the consignee. Demurrage caused by Meridian's error shall be absorbed only with the approval of the Import Team Lead. Each such absorption must be recorded as a cost-absorption decision.

### 4.4 Dispute

When a D&D invoice contradicts the recorded free time, the Import Operator must dispute the invoice with the carrier within 7 days of receipt. The dispute and supporting free-time record shall be retained in the shipment file.

## 5 Empty Return

### 5.1 Return deadline

The trucker must confirm the empty return date in writing. Upon receipt of this confirmation, the Import Operator shall record the return date in the shipment file to close detention exposure.
