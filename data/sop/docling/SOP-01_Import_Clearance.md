## Import Clearance Standard Operating Procedure

Document: SOP-01 Version: v3.2 Effective date: 2025-09-01 Owner: Import Operations, Meridian Freight Co. Approved by: Operations Manager

## 1 Purpose and Scope

## 1.1 Purpose

This procedure defines the mandatory steps that shall be followed for sea import clearance handled by the Import Operations team. All Import Operators and Import Team Leads must comply with the steps set out herein for every applicable shipment.

## 1.2 Scope

This procedure shall apply to all FCL and LCL sea imports where Meridian Freight Co. acts as forwarder or NVOCC. Air imports are outside the scope of this procedure and are covered by SOP-06.

## 2 Roles and Responsibilities

## 2.1 Import Operator

The Import Operator shall own each import file from receipt of the pre-alert through to delivery. The Import Operator must act as the single point of contact for the consignee, customs broker, carrier and trucker throughout the life of the file.

## 2.2 Import Team Lead

The Import Team Lead shall approve all exceptions to this procedure. The Import Team Lead is authorised to sign off on cost absorption up to USD 2,000. The Import Team Lead shall also receive and act upon escalations raised by Import Operators.

## 2.3 Documentation Clerk

The Documentation Clerk shall issue the House B/L for each applicable shipment. The Documentation Clerk must maintain the document register and shall archive all original documents.

## 3 Pre-arrival

## 3.1 Pre-alert review

The Import Operator must review the pre-alert within 1 working day of receipt. As part of this review, the Import Operator shall confirm that the HBL and MBL data match.

## 3.2 Arrival Notice

The Import Operator shall send the Arrival Notice to the consignee no later than 3 working days before ETA. The Arrival Notice must quote the MBL, HBL, container, vessel/voyage, ETA and free time.

## 3.3 Document collection

At the time the Arrival Notice is sent, the Import Operator shall request the commercial invoice, packing list and, where preferential treatment applies, the C/O from the consignee. The Import Operator must refer to SOP-02 for the applicable document checklist.

## 4 Customs Declaration

## 4.1 Broker instruction

The Import Operator must forward a complete document set to the appointed customs broker at least 2 working days before ETA. Incomplete document sets shall not be treated as meeting this requirement.

## 4.2 HS code verification

The Import Operator shall cross-check the HS code proposed by the customs broker against the consignee's import history. Any change to the HS code must be confirmed in writing with the consignee before the declaration is filed.

## 4.3 Duty and tax payment

Duty shall be paid by the consignee directly. The Import Operator must not arrange a disbursement of duty on the consignee's behalf unless the disbursement has been pre-approved by Accounting.

## 5 Inspection and Release

## 5.1 Inspection notice

If customs selects the shipment for physical inspection, the Import Operator must inform the consignee within 1 working day. The Import Operator shall also record the inspection in the file.

## 5.2 Delivery Order

The Import Operator shall request the D/O from the carrier only after both customs release has been obtained and O/BL surrender or telex release has been confirmed. A D/O must not be requested where either condition is outstanding.

## 5.3 Trucking booking

The Import Operator must book trucking at least 1 working day before the planned pick-up. The Import Operator shall provide the delivery slot to the consignee in writing.

## 6 File Closure

## 6.1 Proof of delivery

The Import Operator must obtain a signed POD within 3 working days of delivery. The signed POD shall be attached to the file.

## 6.2 Invoicing handover

The Import Operator shall hand the cost sheet to Accounting within 5 working days of delivery to enable invoicing.
