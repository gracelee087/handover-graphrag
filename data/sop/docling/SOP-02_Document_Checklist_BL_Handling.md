## Import Document Checklist and B/L Handling

Document: SOP-02

Version: v2.0

Effective date: 2025-06-15

Owner: Import Operations, Meridian Freight Co.

Approved by: Operations Manager

## 1 Mandatory Document Set

## 1.1 Checklist

The Import Operator must ensure that the documents listed in the following table are obtained for each import shipment according to its cargo type.

| Document           | Required for    |
|--------------------|-----------------|
| Commercial invoice | All cargo types |
| Packing list       | All cargo types |
| B/L                | All cargo types |
| C/O                | All cargo types |
| Import licence     | Medical devices |
| Health certificate | Food            |

## 1.2 Completeness check

The Import Operator must tick the document checklist in the shipment file before instructing the customs broker. Any missing items shall be chased with the consignee in writing, and the broker must not be instructed until the checklist has been completed.

## 2 Bill of Lading

## 2.1 Master vs House

The Master Bill of Lading (MBL) is issued by the carrier to Meridian, and the House Bill of Lading (HBL) is issued by Meridian to the consignee. The Import Operator must include both the MBL and HBL numbers in the subject line of every email concerning the shipment.

## 2.2 Original B/L

Where an original B/L has been issued, the Import Operator must ensure that all three originals, or one duly endorsed original, are surrendered before cargo is released. Cargo shall not be released until this surrender requirement has been met.

## 2.3 Telex release / Sea waybill

Where the carrier provides a telex release confirmation, this confirmation shall replace the surrender of the original B/L. The Import Operator must file a screenshot of the telex release confirmation in the shipment file.

## 2.4 Release confirmation before D/O

The Import Operator must not send any D/O request to the carrier until surrender of the original B/L or telex release has been confirmed. The confirmation must be recorded in the shipment file before the D/O request is issued.

## 3 Amendments

## 3.1 B/L correction

Any B/L amendment requested after vessel departure shall require a written request from the shipper and an acknowledgement from the consignee. The Import Operator must obtain both documents before processing the amendment, and any amendment fees must be quoted to the party requesting the amendment.

## 3.2 Manifest correction

The Import Operator must file any manifest corrections at destination before the vessel's ATA. Any correction that cannot be filed before the ATA shall be escalated to the Import Team Lead.

## 4 Archiving

## 4.1 Retention

All import documents shall be retained for 5 years in the document management system. The Documentation Clerk must ensure that each shipment's documents are archived in the system for the full retention period.
